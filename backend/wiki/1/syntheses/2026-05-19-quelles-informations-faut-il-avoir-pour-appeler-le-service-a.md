### Informations requises pour contacter le service après-vente (SAV) Jenny Compressor

Pour contacter le **service après-vente Jenny Compressor**, vous devez préparer les informations suivantes afin de faciliter l'assistance :

#### 1. **Informations obligatoires**
Ces informations sont **indispensables** pour identifier votre équipement et fournir une assistance précise :
- **Numéro de modèle de la machine** : Exemple : *Jenny 100-A*, *Jenny 200-B*, etc.
- **Lettre du modèle de pompe** ou **numéro de modèle de la pompe** : Cette information est généralement indiquée sur une plaque signalétique située près de la pompe ou dans le manuel.
- **Numéro de série de la machine** : Ce numéro est unique et permet de retracer l'historique de fabrication et de maintenance de votre compresseur.

*Source : [JennyCompressorManual.pdf, p.3]*


#### 2. **Informations complémentaires utiles**
Pour accélérer le traitement de votre demande, préparez également :
- **Description détaillée du problème** : Symptômes observés (ex : bruit anormal, fuite d'huile, surchauffe, perte de pression).
- **Contexte d'utilisation** : Fréquence d'utilisation, environnement (poussiéreux, humide, etc.), et toute modification récente apportée à l'équipement.
- **Historique de maintenance** : Dates des dernières interventions (vidanges, changements de filtres, etc.) et pièces remplacées.


#### 3. **Canaux de contact**
Le manuel JennyCompressorManual.pdf indique que vous pouvez contacter le SAV :
- **Via un distributeur agréé Jenny** : Si vous avez acheté votre compresseur auprès d'un distributeur, celui-ci peut servir d'intermédiaire pour le SAV.
- **Directement** : Le manuel mentionne un contact direct, mais ne fournit pas les coordonnées précises (numéro de téléphone, email, site web).

Pour obtenir les **coordonnées complètes du SAV Jenny**, consultez :
- **La plaque signalétique** de votre compresseur : Elle peut contenir un numéro de support ou un site web.
- **Le manuel complet** : Les dernières pages ou la section "Contact" peuvent fournir des informations supplémentaires.
- **Le site web officiel de Jenny Compressor** : Recherchez "Jenny Compressor support" ou "Jenny Compressor contact" pour trouver les coordonnées actualisées.


#### 4. **Recommandations**
- **Vérifiez les garanties** : Si votre compresseur est encore sous garantie, munissez-vous de votre preuve d'achat.
- **Prenez des photos** : Si le problème est visuel (ex : fuite, pièce endommagée), des photos peuvent aider le SAV à diagnostiquer plus rapidement.
- **Notez les codes d'erreur** : Si votre compresseur affiche un code d'erreur, mentionnez-le lors de votre appel.
