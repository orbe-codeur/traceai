### Procédure pour purger le condensat du réservoir d'air d'un compresseur Jenny

#### **1. Pourquoi purger le condensat ?**
Le condensat (mélange d'eau et d'huile) s'accumule dans le réservoir d'air en raison de la condensation de l'humidité présente dans l'air comprimé. Si ce condensat n'est pas évacué régulièrement, il peut entraîner :
- **Corrosion** du réservoir et des composants internes.
- **Risque d'explosion** en cas d'accumulation excessive de vapeur ou de pression.
- **Détérioration de la qualité de l'air** distribué (présence d'eau ou d'huile dans les outils pneumatiques).

> **Fréquence** : La purge doit être effectuée **après chaque utilisation** du compresseur pour éviter ces risques. [[JennyCompressorManual.pdf, p.10] ; Skill : maintenance-purge-condensat-compresseur-jenny].

---

#### **2. Prérequis**
##### **Outils nécessaires**
- Un récipient adapté pour récupérer le condensat (ex: bac de vidange, seau).
- Des équipements de protection individuelle (EPI) : gants et lunettes de sécurité.
- Un chiffon propre pour essuyer les éventuelles projections.

##### **Sécurité**
⚠️ **Risques** :
- **Brûlures** : Le réservoir et le condensat peuvent être chauds.
- **Projection de condensat** : Le condensat peut être sous pression et contenir des contaminants.
- **Électrocution** : Assurez-vous que le compresseur est **éteint et débranché** avant toute intervention.

**Étapes de sécurité** :
1. **Éteindre le compresseur** et le débrancher de la source d'alimentation électrique.
2. **Laisser refroidir** le réservoir si le compresseur a été utilisé récemment.
3. **Porter des EPI** (gants et lunettes) pour se protéger des projections.

---

#### **3. Étapes détaillées pour purger le condensat**
Les étapes suivantes sont basées sur les **bonnes pratiques industrielles** pour la purge des réservoirs d'air comprimé. Elles s'appliquent aux compresseurs Jenny, mais il est recommandé de vérifier la localisation exacte du robinet de purge dans le **[JennyCompressorManual.pdf, p.10]** ou sur la machine.

1. **Localiser le robinet de purge** :
   - Le robinet de purge est généralement situé **au point le plus bas du réservoir**, car le condensat s'y accumule par gravité.
   - Sur les compresseurs Jenny, il peut s'agir d'un **robinet manuel** ou d'un **purgeur automatique** (selon le modèle). Dans le doute, consulter le manuel constructeur.

2. **Placer un récipient sous le robinet de purge** :
   - Utiliser un bac ou un seau pour récupérer le condensat. **Ne pas laisser le condensat s'écouler sur le sol**, car il peut être glissant ou polluant.

3. **Ouvrir le robinet de purge** :
   - Tourner lentement le robinet dans le sens inverse des aiguilles d'une montre pour l'ouvrir.
   - Laisser s'écouler **tout le condensat** jusqu'à ce que seul de l'air sorte (aucun liquide ne doit plus couler).
   - Si le robinet est bloqué ou difficile à ouvrir, **ne pas forcer** : consulter un technicien qualifié.

4. **Fermer le robinet de purge** :
   - Une fois la purge terminée, refermer le robinet en le tournant dans le sens des aiguilles d'une montre.
   - Vérifier que le robinet est bien fermé pour éviter les fuites d'air.

5. **Vérifier l'état du condensat** :
   - **Inspecter visuellement** le condensat récupéré :
     - Une couleur **laiteuse ou blanche** indique une présence normale d'eau.
     - Une couleur **noire ou marron** peut indiquer une contamination par de l'huile ou des particules métalliques (signaler ce cas pour une maintenance approfondie).

6. **Éliminer le condensat** :
   - Le condensat est considéré comme un **déchet polluant** (mélange d'eau et d'huile).
   - **Ne pas le jeter à l'égout ou dans la nature** : le récupérer dans un récipient adapté et le confier à un service de traitement des déchets industriels.

7. **Redémarrer le compresseur** :
   - Une fois la purge terminée, rebrancher le compresseur et le redémarrer.
   - Vérifier qu'il n'y a **aucune fuite d'air** au niveau du robinet de purge.

---

#### **4. Bonnes pratiques supplémentaires**
- **Automatiser la purge** : Si le compresseur est utilisé fréquemment, envisager l'installation d'un **purgeur automatique** pour éviter les oublis.
- **Tenir un registre** : Noter la date et l'heure de chaque purge dans un **registre de maintenance** pour assurer un suivi régulier.
- **Former les utilisateurs** : S'assurer que tous les utilisateurs du compresseur connaissent la procédure de purge et les risques associés.
