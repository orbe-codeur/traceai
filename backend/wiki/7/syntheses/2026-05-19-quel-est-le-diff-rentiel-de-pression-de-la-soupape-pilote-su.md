### Différentiel de pression de la soupape pilote sur un compresseur Jenny

#### **1. Définition du différentiel de pression**
Le **différentiel de pression** (ou *pressure differential*) est la différence entre :
- La **pression de coupure** (*cut-out pressure*) : pression maximale à laquelle le compresseur s'arrête.
- La **pression de redémarrage** (*cut-in pressure*) : pression minimale à laquelle le compresseur redémarre.

Exemple : Si la pression de coupure est **130 psi** et la pression de redémarrage est **100 psi**, le différentiel est de **30 psi**. 

---

#### **2. Réglage du différentiel sur un compresseur Jenny**
Le différentiel de pression est réglé via le **barillet 'C'** situé sur la soupape pilote. Voici les étapes pour l'ajuster :

1. **Localisation** :
   - La soupape pilote est généralement située sur le réservoir ou près du pressostat.
   - Elle comporte :
     - Une **vis 'A'** (réglage de la pression de coupure).
     - Un **écrou de verrouillage 'B'** (pour bloquer la vis 'A').
     - Un **barillet 'C'** (réglage du différentiel de pression).

2. **Réglage** :
   - **Tourner le barillet 'C' dans le sens horaire** pour **augmenter** le différentiel.
   - **Tourner le barillet 'C' dans le sens anti-horaire** pour **diminuer** le différentiel.
   - **Ne pas desserrer le barillet 'C' de plus d'un tour** pour éviter les risques de dépressurisation brutale.

3. **Exemple concret** (source : [JennyCompressorManual.pdf, p.40]) :
   - Si le différentiel actuel est **100-130 psi** (soit **30 psi**) et que vous souhaitez le réduire à **100-120 psi** (soit **20 psi**), tournez le barillet 'C' dans le sens **anti-horaire**.

---

#### **3. Valeur par défaut du différentiel**
Le manuel constructeur **JennyCompressorManual.pdf** ne précise pas une valeur universelle pour le différentiel de pression. Cependant :
- Un **exemple typique** mentionné dans le manuel est **30 psi** (ex. : 100-130 psi).
- La valeur par défaut peut varier selon le **modèle du compresseur** et son **usage** (industriel, domestique, etc.).

**Recommandation** :
- Consulter le **manuel spécifique du modèle** pour connaître la valeur par défaut exacte.
- Si le manuel n'est pas disponible, mesurer les pressions de coupure et de redémarrage avec un **manomètre de précision** pour calculer le différentiel.

---

#### **4. Pièges à éviter**
- **Différentiel trop faible** : Peut provoquer un **battement (*chatter*)** de la soupape pilote, entraînant une usure prématurée.
  *Solution* : Augmenter le différentiel en tournant le barillet 'C' dans le sens **horaire**.
- **Différentiel trop élevé** : Peut entraîner des **cycles de marche/arrêt trop longs**, réduisant l'efficacité du compresseur.
- **Oublier de verrouiller le barillet** : Toujours resserrer l'écrou 'D' après ajustement pour éviter un déréglage accidentel.
